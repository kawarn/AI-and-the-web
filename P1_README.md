Read me file for project one:

idea:
Our idea was to create a guessing with words. So we had to options in our mind: Let the player guess letter for letter and highlight the right ones (maybe give tips for the location in the alphabet of the right letter) oder let the player guess whole words an highlight the right letters at the right place (here tips would include the length of the word and the placement of corect letters) 
In our opinion the second option would be more fun. After some thinking we decided to give our guessing game a similar structure like the game "wordle". 

first programming steps:
To create a basic framework for our programm we used the word "apple" as a correct solution and built our programm around it. We wanted the word length limited to five letters and a reasonable response to user inputs. So the first steps were to create practical outputs, an user input and responses to that. Once we had everything set up so a working guessing game with the word "apple" was possible, we thought about how we could create a collection of five-letter words and save the users' stats.
